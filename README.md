💬 Sentiment Analysis with NLP

This project demonstrates how to perform Sentiment Analysis on customer reviews using Natural Language Processing (NLP) techniques. It uses TF-IDF Vectorization to convert text data into numerical features and applies Logistic Regression for classification.

📂 Project Overview
🧹 Text Preprocessing: Cleaning, lowercasing, removing stopwords, stemming.

🧠 Feature Extraction: Using TF-IDF to vectorize text.

🤖 Modeling: Training a Logistic Regression model to classify sentiment (positive or negative).

📊 Evaluation: Confusion matrix, accuracy score, and classification report.

📁 Files Included
Sentiment_Analysis_TFIDF_LogisticRegression.ipynb: Main Jupyter Notebook with complete implementation.

sample_reviews.csv: Sample dataset of 10 customer reviews with labeled sentiments (1 = Positive, 0 = Negative).
